# Domain Docs

Layout: multi-context

`CONTEXT-MAP.md` at repo root points to per-context `CONTEXT.md` files.
ADRs live at repo root as `0001-*.md` through `0006-*.md` (flat, no `docs/adr/`).

## Consumer Rules

- Read `CONTEXT-MAP.md` first to locate the relevant `CONTEXT.md` for the target area.
- ADRs are normative and closed -- do not contradict them without a new ADR.
- `CONTEXT.md` is the single source of term definitions -- never redefine terms inline.
